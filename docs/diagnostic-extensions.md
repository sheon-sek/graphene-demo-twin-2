# Diagnostic Extensions

Extensions are generated only for equipment families whose exported UDT surface is insufficient for causal diagnosis. They add command/feedback/flow/pressure/power/state evidence for CRACs, chillers, pumps, valves, towers, PAHUs/FWUs/FCUs, UPSs, gensets and CDUs. Each extension has `origin=twin-extension` and `extensionReason=AI-diagnostic-observability`.
